末日清扫员 1.7.0 / Windows 便携版

解压后双击 ScrapRunner-1.7.0.exe。需要已安装 Microsoft Edge 或 Google Chrome。
游戏与素材包含在 EXE 内，释放到本机用户目录后运行。保留原有浏览器存档。

开局：跳过或阅读剧情，进入机库，选择武器、流派、一个星相和一个碎片，再点击出击。
三种免费开局武器：手枪（保留原有射击）、动力刀剑（三连斩）、重型火炮（慢速范围破甲）。
三种流派：烈焰工程师（叠热能点燃、击杀回血）、雷霆游侠（连锁、回补、疾行）、虚空守卫（削弱、坍缩、护盾）。
星相选择一个核心被动，碎片选择伤害强化、击杀返还 Q 冷却或生命上限 +15。各流派都可搭配任意开局武器。

WASD / 方向键：移动。鼠标：瞄准。按住左键：攻击。无人机与环绕锯刃自动工作。
Q：流派攻击，8秒基础冷却。E：流派辅助，18秒基础冷却。R：满能量过载，持续6秒。P：暂停。
点击底部技能按钮可查看当前流派说明，并暂停游戏；关闭或 Esc 后恢复。
点击右上“装备 / 进化”查看装备、星相与碎片；点击“设置”调整震动、伤害数字、特效和音量。
新走路动画按移动距离推进，包含落脚、后蹬、抬膝、重心与摆臂；持械与射击反馈随武器变化。

每局最多4武器+4模块，特殊武器由每5波母虫掉落；支持手枪、电弧、锯刃进化。
每张地图20波，清场休息5秒。最终Boss有预警跃击、二阶段机关、三阶段900护盾（危险难度1080）。
30秒内未破盾会自爆500伤害并导致区域毁坏失败。Boss血量6200 / 5800 / 7000，阶段伤害倍率1 / 2 / 4。
冰原：寒冷100冻结5秒；解冻后3秒保护。冰爆虫接触冻结，冰棘虫远程射击。
熔炉：命中附加5秒灼烧，每秒3伤害；喷焰虫扇形远程攻击。回收场有酸液射手。

进度在本机浏览器保存。失败保留挑战进度，解锁武器、机甲与地图。
声音需要首次点击后启用，可点击右上“开启声音 / 试听”。

1.7.0 武器外观与刀剑修复：
手枪、火炮、刀剑使用独立透明高细节贴图，接入战斗持械与机库卡片；素材加载失败时保留机械轮廓绘制后备。
刀剑有效范围与刀光统一为半角1.25弧度（约143度扇形）；普通半径86，过载112。计入敌人碰撞半径并提供3像素边缘容错，挥刀有效期间持续检查新进入的敌人。每次挥刀对同一敌人只结算一次，避免帧率影响伤害。
暂停与冻结不执行命中结算。过载时刀光时长不超过攻击间隔，避免上一刀残留误导。
新增测试覆盖径向/角度边缘、跨正负π方向、挥刀期间进入、重复命中与过载时长。


1.7.0 场景与动作
- 三张独立1536×1024场景：废城混凝土/铜锈、极寒科研设施/结霜金属、地下熔炉/厚重钢板。建筑集中于边缘，地面保持可行走；渲染时裁切适配原战斗边界，不新增不可见障碍。
- 保留240秒光照循环，降低夜间遮罩强度；冰原72秒风雪强弱循环、熔炉余烬和反应炉明暗、废城浮尘。环境特效位于角色/伤害预警下层，可由特效设置关闭；暂停时停止。
- 每96像素一轮步态，12个采样帧，连续插值；斜向移动混合横向步幅与纵向缩短步幅。转向不重置左右脚相位。
- 朝向使用指数平滑，鼠标方向采用额外约7度防抖阈值，上身90ms切换过渡；瞄准时抑制摆臂，停步有呼吸起伏。
- 刀剑视觉分为16%衔接、66%主挥斩、18%随动；结束后从末端姿势恢复，保留1.6.1连续扇形碰撞与每刀单次伤害。动作插值不增加移动或射击判定延迟。
- 已检查48帧四方向序列、三个实际Canvas战斗画面与危险预警。没有进行人工浏览器试玩；需继续根据玩家反馈调整手感。
